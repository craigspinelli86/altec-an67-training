Module 01 · Foundation
System Overview
Before you touch anything, understand what you're dealing with. The AN67-E100 has two separate hydraulic power sources, a dedicated PTO-driven main pump, and a layered interlock system. Every diagnosis starts here.
By the end of this module you will
  • Know the difference between the PTO-driven main pump and the emergency DC pump
  • Understand the boundary between the Freightliner chassis and the Altec upfit
  • Know the sequence of events from park brake to boom operation
  • Understand the unit's structural architecture and key specs

Think Like a Senior Tech

Most misdiagnoses happen because a tech jumped straight to a component without understanding the system. This unit has three interdependent systems. When something doesn't work, your first job is to figure out which system owns the fault — electrical/PDM, hydraulic, or chassis — before you start swapping parts.

The Golden Rule Every time you get a complaint on this unit, ask three questions in order: Are all interlock conditions satisfied? Is hydraulic power actually reaching the control valves? Is the downstream device (solenoid, cylinder, valve) doing its job with that input?

Sequence of Events: Park Brake to Boom

Walk through this mentally on every "no function" complaint. Each step depends on the one before it.

  1. Park brake engaged, transmission in neutral. Both conditions required before PTO will engage. Park brake signal feeds the interlock circuit.
    2. If PTO won't engage, verify both conditions are met. Park brake disengagement after PTO is on will immediately kill both PTO and all machine functions.
  2. PTO switch activated. PDM PTO Card (650-50003) evaluates interlock conditions and sends enable request to the Allison. The PTO Card's auto-neutral function requests that the Allison hold in neutral.
    3. PTO will not engage in any gear other than neutral. The auto-neutral behavior is managed by the PTO Card programming (AUTONEUTRAL enabled per schematic) — it sends a request to the Allison, it doesn't override the transmission independently.
  3. Main pump driven via hotshift PTO. Variable displacement piston pump begins responding to load-sense demand from control valves.
    4. Engine RPM affects pump output. Per the schematic programming parameters: Remote PTO Set Speed 1 is 875 RPM, Set Speed 2 is 1,200 RPM (labeled "speed for max hydraulic flow"), and Set Speed 3 is set the same as Set Speed 2 (1,200 RPM). PTO maximum speed is programmed at 1,400 RPM. ENG RPM:OPER is 1,650.
  4. All outriggers extended and locked. Outrigger interlock switches (one per leg) must all be made. Interlock solenoid in the lower control mounted control valve energizes, opening the load-sense path to the pump.
    5. One outrigger not fully down = interlock solenoid stays de-energized = no boom operation. This is the most common cause of "boom dead, PTO on" complaints.
  5. Operator commands a function. Upper controls pilot system (375 psi per maintenance manual) opens the blocking valve in the lower control valve or elevator control valve. Spool shifts, flow goes to the cylinder.
    6. Boom won't move with outriggers set and PTO on? Confirm the blocking valve is receiving pilot pressure — check that the upper controls selector is in the correct position and the interlock trigger is being engaged.

What Matters for Troubleshooting — Start Here

All circuits on this unit are on/off — no analog control signals in the basic architecture. A switch or relay closes, power reaches the component; it opens, power stops. The four most common causes of no-function in the field:

The Four Field Killers 1. Park brake not set — disengaging it after PTO kills both PTO and all machine functions immediately.
2. Outrigger interlock not satisfied — all outrigger legs must make their individual switches.
3. PDM relay or start/stop circuit fault — check PDM connector center screw first.
4. PTO engaged in the wrong transmission state — the Allison will not accept the enable request unless in neutral.

PTO Engagement Circuit — Full Trace

  1. Park brake set + transmission in neutral. Both conditions required. The PDM PTO Card monitors these before allowing the enable request.
    2. PTO won't engage with either condition missing. The PTO Card programming includes an auto-neutral request to the Allison — but the transmission must already be in neutral for the engage to succeed. It will not shift a transmission that's in gear.
  2. PTO switch activated. Signal travels to the PDM PTO Card (650-50003). Card evaluates interlock conditions and sends the enable request to the Allison.
    3. If PTO won't engage, this is the first split point. Is the park brake signal reaching the interlock circuit? Is the transmission neutral signal present? Check both inputs before assuming a module fault.
  3. PTO Card sends enable request to Allison via PTO circuits 112, 114, 117, 118, 155, 161. Active Package: 223.
    4. PTO circuits use Jumpers J1/J2/J3 to configure for Allison 3K/4K vs 1K/2K. Verify jumper settings on any replacement PTO card.
  4. PTO engages hotshift mechanism. Drives main pump via 161% ratio at street-side (left) PTO opening.
    5. PTO engaged but pump not spinning? Verify the hotshift mechanism is actually actuating. This is now a mechanical/chassis concern — not PDM.
  5. Engine throttle commanded. Throttle Card (650-50015) sends command to engine. Per schematic: Remote PTO Set Speed 1 = 875 RPM, Set Speed 2 = 1,200 RPM (speed for max hydraulic flow), Set Speed 3 = same as Set Speed 2 (1,200 RPM). PTO maximum speed = 1,400 RPM. ENG RPM:OPER = 1,650.
    6. Engine stays at idle with PTO on? Check the throttle card output and engine ECM interface. Verify the correct throttle card version is installed for the Cummins L9.

How the Main Pump Works

The main pump is a variable displacement, pressure-compensated piston pump. It doesn't run at full output all the time — it adjusts flow to match exactly what the system needs at any moment.

The pump reacts to a load-sense (LS) signal returned from the control valves. Move a function and the valve sends a signal pressure to the pump telling it how much flow and pressure is needed. The pump matches it. Nothing moving? The pump goes to low-pressure standby. This is why standby pressure is a valuable diagnostic check — a pump at the wrong standby tells you something is wrong before you even command a function.

Diagnostic Principle Before condemning any hydraulic component, check standby pressure at the pump test port (marked PD on the lower control valve). Standby spec is 475–500 psi (per maintenance manual) with all functions off and the aerial device selector active. Correct standby with no function = problem is downstream (valve, solenoid, cylinder). No standby or wrong standby = problem is at the pump or its load-sense circuit.

How Outrigger Pressure Is Built 1,500 PSI load-sense signal + 500 PSI from tool control valve + 500 PSI pump compensator = 2,500 PSI outrigger circuit. The tool circuit then takes that 2,500 PSI and subtracts 500 PSI to produce the 2,000 PSI tool pressure. These are not independent settings — they're derived from each other.

The 13.5 GPM / 11.0 GPM Split

The hydraulic schematic shows two flow values: 13.5 GPM and 11.0 GPM. This is one pump routing flow to two separate valve circuits simultaneously — not two pumps.

The 13.5 GPM path feeds boom functions through the lower control valve. The 11.0 GPM path feeds elevator functions through the elevator control valve. When both are operated at the same time, the pump supplies both circuits simultaneously.

Within each circuit, shuttle valves in the load-sense line handle priority. Two boom functions running together? The shuttle valve passes the highest pressure demand to the pump. Each spool has its own pressure compensator — if one function needs less than what the pump is delivering, the compensator throttles that spool's flow automatically. Functions run at correct speed regardless of what else is active.

Note on Flow Figures The hydraulic pump spec sheet (P/N 990280340) lists pump rated flow as 15 GPM. The maintenance manual (Section 5) states the pump delivers 28 gpm at 3,000 psi, and the hydraulic spec sheet lists unit flow rate as 28.0 GPM. The 28 GPM figure represents the system flow demand, while 15 GPM is the pump's rated output speed. Always verify against your specific unit's documents when ordering or diagnosing.

Control Valve Architecture

Aerial Device / Outrigger Selector Valve — First Routing Point ▼

Located at the tailshelf, ground-level controls. This is where flow is directed after the pump — before it reaches any boom or outrigger circuit.

  • De-energized (default): Aerial device mode — oil routes to lower control valve, outrigger circuit blocked
  • Energized: Outrigger mode — oil routes to outrigger circuit, lower control valve blocked
  • Contains: outrigger interlock solenoid, pressure control valves, tools flow control valve, and a system relief valve
  • Tool flow adjustable from 0.3 to 10.6 GPM via the tools flow control valve
If the boom is dead but outriggers work normally (or vice versa), confirm the selector solenoid is in the correct state. A selector stuck in the wrong mode silently blocks one entire circuit.
Lower Control Valve — Boom Functions (Turntable) ▼

Contains: pilot and purge pressure reducing valves, automatic purge valves, bypass valve, boom stow solenoid, station selector valve, overcenter blocking section, and three boom spools plus the winch. Each spool is 3-position, 4-way, spring-centered.

The load-sense shuttle valve network between spools sends the highest demand to the pump. Section pressure compensators on each spool let multiple functions run accurately simultaneously.

One boom function slow while others are fine? The problem is at that section's spool or compensator — not at the pump. Check the electrical command signal to that spool's solenoid before opening the valve.
Elevator Control Valve — Elevator Functions ▼

Parallel architecture to the lower control valve, dedicated to elevator functions. Contains pilot/purge valves, bypass valve, elevator stow pressure limiters, station selector, and two elevator spools. Same load-sense shuttle valve logic — highest demand wins.

Elevator function speed is adjusted via the section pressure compensator on each spool. The elevator stow valve (solenoid-operated, 2-position, 2-way) with pressure switch prevents elevator damage from debris during stowing.

Holding Valves — How to Test Them

Holding valves keep cylinders in position under load and prevent drift if a hydraulic line fails. Two types are used:

Pilot Operated Check Valves — Where Used and How to Test ▼

Used on: Outrigger cylinders, jib tilt, jib extension, platform tilt. Installed in cross-ported pairs — oil to one port pilots open the opposite check valve.

Test: Position the cylinder under load, disengage PTO, fully shift the manual lever. If the cylinder doesn't move, the holding valve is working. Slow retraction after shifting = holding valve may be leaking. Find root cause before returning to service.

Counterbalance Valves — Overrunning Load Cylinders ▼

Used on cylinders with overrunning loads. Cross-ported, same pilot-to-open concept as check valves. Same test procedure.

Use a test block to adjust the relief setting on counterbalance valves during testing — do not attempt to adjust with the boom in a loaded position.

Common Hydraulic Failure Patterns

All Functions Slow or Weak ▼
  • Every boom and elevator function is equally slow
  • May worsen as oil heats up
  • No noise difference between functions

Think about

All functions equally slow = fault is upstream of all valves. Check hydraulic oil level first (must check with all booms stowed, outriggers retracted, vehicle level). Then check PTO engagement and engine RPM — correct throttle set speed must be reached. Pump standby pressure and flow test if those check out.

One Function Slow, Others Normal ▼
  • One specific movement is slow or weak
  • All other functions perform normally
  • May be accompanied by noise from that spool section

Think about

One section affected = problem is downstream of the pump at that specific spool. Before opening the valve, check the electrical command signal to that spool's solenoid and verify full voltage is reaching it. Partial voltage on a solenoid (high resistance connection) produces slow, weak movement that looks exactly like a stuck spool.

Pump Runs But No Function At All ▼
  • Main pump is running (feel or hear it)
  • No boom, no elevator, no outrigger movement
  • No load-sense pressure at valve inlet

Think about

Check outrigger interlock solenoid first — if it's not energized, the load-sense path to the pump is blocked and no flow will be demanded. If outriggers are all confirmed down and the interlock solenoid is energized, check whether the aerial device/outrigger selector valve is in the correct mode. Then check standby and working pressure at the pump.

Pump Cavitation / Noise After Repair ▼
  • Whining or unusual noise from pump immediately after hydraulic work
  • Spongey or inconsistent boom movement
  • Fluid temperature rising faster than normal

Think about

After any repair that opened the suction circuit, air gets in. Back off immediately — do not run the pump hard against a cavitating load. Check all suction-side fittings you opened: a fitting that isn't fully torqued will pull air under suction vacuum without showing visible fluid loss under pressure. Cycle all functions slowly and repeatedly at minimal load to work air back to the reservoir.

Don't Condemn the Pump Post-repair cavitation is almost always air in the suction circuit — not pump damage. Replacing the pump without fixing the air entry point means the replacement will cavitate too.

Secondary Stowage DC Pump

Fixed displacement, under 2.5 GPM, battery-powered. Its only function is emergency stow when the main system is unavailable. Activate from turntable toggle switch or captive air system at upper controls. Do not use for aerial work.

When diagnosing a stowage failure, check in this order: battery charge state → DC pump motor wiring → PDM pump relay connection (center screw tightened) → pump motor itself. Low battery voltage will produce weak pump performance that looks like a failed motor.

Outrigger Interlock System

The outrigger interlock is an electric/hydraulic combination that blocks boom operation until every outrigger leg is fully lowered. One switch per leg — all switches must make before anything clears.

  1. Each leg has its own interlock switch. All are monitored simultaneously by the interlock control module.
    2. Physically confirming an outrigger is "down" is not the same as confirming its switch is made. Inspect switch position, wiring, and whether the leg has fully reached the switch actuation point.
  2. All switches made → module energizes the interlock solenoid in the lower control mounted control valve. This opens the load-sense path to the pump. Boom operation is now possible.
    3. The interlock solenoid is the hydraulic gate. Without it energized, the pump has no demand signal and produces no working pressure regardless of RPM or PTO status.
  3. Any leg raised or retracted → solenoid de-energizes immediately. Load-sense path blocked. All boom movement stops, mid-function if necessary.
    4. This is a safety feature. It is not a fault. If boom movement unexpectedly stops, check whether an outrigger shifted or lost contact before chasing electrical faults.

Lanyard Detection System

The lanyard interlock system, if equipped, prevents aerial unit operation from the upper controls if the operator's lanyard is not attached. Important: per the maintenance manual, this system only prevents unit operation when the selector is in the upper controls position. Four components work together:

ComponentRole
Lanyard Fiber Optic SwitchDetects whether the lanyard is properly attached
Single Handle Fiber Optic SwitchMonitors single handle control interlock engagement state
Fiber Optic TransceiverReads and interprets optical signals from both switches
Lanyard Interlock System Control ModuleProcesses signals and activates the unit motion blocking valve when interlock is not satisfied

The system also has an anti-tie-down feature: at every PTO cycle, it detects whether an object is already satisfying the switch. If something is detected at the start of a PTO cycle (tied-down), the object must be removed to resume normal operation. The audible alarm chirps to indicate tie-down mode.

Override is possible via the turntable override momentary control (held longer than the preset time, default 0.5 seconds). Override is also activated when entering secondary stowage mode. The schematic also shows switch S14 (SENSE MODE / OVRIDE SENSE) — use per documented service procedures only, not during normal aerial operations.

Elevator Stow Valve Logic

The elevator stow valve is a solenoid-operated, 2-position, 2-way valve with a pressure switch at the lower controls. This combination prevents the elevator from slamming into debris during the stow stroke.

  1. Lower elevator cross link activates a switch on the lower elevator arm as stowing progresses.
  2. Switch activation sends current to the stow solenoid, closing the valve.
  3. Valve closing stops elevator stow movement at the correct position.
Elevator Stow Alarm Active If the stow alarm is active, the elevator has not reached its stow position. Check whether the cross link is actually contacting its switch. Also inspect under the elevator assembly for debris that may be blocking the final stow stroke. The pressure switch monitors for obstructions.

Module 05 · Diagnostics
Diagnostics
Systematic diagnosis on this unit means tracing the signal path in order — don't skip layers. Electrical supply → interlock conditions → PDM relay → downstream device. Every time.
By the end of this module you will
  • Use the electrical/hydraulic path to isolate faults in the correct order
  • Know what to verify at each level before moving to the next
  • Understand rotary joint and slip ring inspection points
  • Know the correct manual lowering/stowing sequence

Diagnostic Sequence — Use This Every Time

  1. Verify interlock conditions are satisfied. Park brake set. Transmission in neutral. All outrigger switches making. PTO engaged. If any condition is not met, nothing downstream will work.
    2. Most "no function" complaints are resolved at this step. Do not skip it to look clever — it saves time.
  2. Confirm the aerial device/outrigger selector valve is in the correct mode. Aerial device mode is de-energized (default). Confirm with the tailshelf selector switch position.
    3. Selector stuck in outrigger mode = boom dead, outriggers work. Stuck in aerial mode = outriggers won't work from ground controls.
  3. Check standby pressure at the PD test port on the lower control valve. Spec is 475–500 psi with all functions off and aerial device selector active. Correct standby with no function = downstream problem. No standby = pump or load-sense circuit.
    4. Before servicing the pump, close both shutoff valves: suction line valve (reservoir to pump) and return line valve (near return port or return line filter).
  4. For a specific function failure, verify the electrical command signal to that spool's solenoid. Is the command reaching the solenoid? Does the solenoid coil have correct resistance?
    5. Solenoid coil resistance test: measure across the solenoid terminals with power off. An open reading (infinite resistance) = failed coil. Short (near zero) = shorted coil. Either requires replacement.
  5. If electrical checks pass, test holding valve function per the manual. Load the cylinder, disengage PTO, shift lever. No movement = holding valve good. Slow drift = holding valve leak.
    6. A leaking holding valve on a boom or elevator cylinder is a safety issue — do not return to service until corrected.

Rotary Joint and Slip Ring Inspection

The rotary joint is a common wear point on high-hour units. At the same time, the slip ring (mounted at the bottom of the rotary joint) carries all electrical signals through the turntable rotation axis.

Rotary Joint Removal — Key Points ▼
  1. Position the unit on level surface, park brake applied, wheels chocked. Engage PTO and set outriggers.
  2. Disconnect the two slip ring connectors inside the turntable and the connector in the pedestal. Do not cut any wires — connectors will pass through the bore once disconnected.
  3. Disconnect all hydraulic hoses from the rotary joint. Cap or plug all open ports immediately.
  4. Remove cap screws securing the restraint bracket to the rotary joint and pedestal.
  5. Remove cap screws mounting the inner core to the mounting plate. Remove the rotary joint/slip ring assembly.
Debris Warning Do not allow debris to accumulate around the rotary joint — it can damage the connected hoses. Do not pressure wash the joint directly. After installation, operate each function five or six times to purge air.

Manual Lowering / Emergency Stow Sequence

If the engine stops with the boom extended, the DC stowage pump provides limited hydraulic flow for stowing only. Follow this sequence exactly — order matters.

  1. Activate DC pump from turntable toggle switch or captive air system at upper controls.
  2. Rotate the turntable to a safe position if needed.
  3. Lower the upper boom to horizontal position.
  4. Lower the lower boom toward stow.
  5. Lower the lower elevator arm.
  6. Lower the upper elevator arm.
  7. Raise the outriggers once all boom components are stowed. Confirm 13' (3.96 m) travel height before moving the vehicle.
DC Pump Limitation The DC stowage pump produces under 2.5 GPM. Movements will be significantly slower than normal. Do not attempt to use this pump for any aerial work — stow only.

Hydraulic Oil Check — Conditions That Matter

Oil level readings are only accurate when: all booms are stowed, all outriggers are retracted, and the vehicle is on level ground. Any other position will give a false reading. After adding oil, recheck under these conditions before releasing the unit.

If oil viscosity is not rated for the ambient temperature, it will cavitate the pump on cold starts — destroying the pump quickly. Match oil viscosity to your operating temperature range. Replace the filler breather cap and clean the suction strainer every oil change.

✓ Correct. The maintenance manual is explicit: oil level must be checked with all booms stowed, outriggers retracted, and vehicle level. Boom position changes the volume of oil in the cylinders vs. the reservoir — a raised boom shifts oil into cylinder rods, making the reservoir read lower than actual fill. Both conditions (boom position AND vehicle level) affect the reading.
Both the boom position and vehicle level matter. When the boom is raised, oil fills the extended cylinders — less stays in the reservoir, so the reservoir reads low even when filled correctly. Scenario 01 · Electrical
PTO Won't Engage — Switch Pressed, Nothing Happens
▼

Symptoms

  • PTO switch pressed — no engagement
  • Engine stays at idle, no throttle response
  • No boom function
  • No audible PTO click or mechanical engagement

Step-by-Step Diagnosis

  1. Confirm both interlock conditions are met: Park brake set AND transmission in neutral.
    2. PTO won't engage in gear. PTO won't engage without park brake. These are not optional — confirm both before going deeper. The Allison transmission must be in neutral to accept the PTO enable request.
  2. Check whether the PTO switch signal is reaching the PDM. Is wire F33 (14 AWG RED, TB11-9) receiving the PTO/clutch output when commanded?
    3. No output at TB11-9 when conditions are met = the PDM PTO Card (650-50003) is not producing output. Verify the card is correctly configured for the Allison 3K/4K series (Jumpers J1/J2/J3 per schematic).
  3. If PTO Card output is present, check the signal path to the Allison via PTO circuits 112, 114, 117, 118, 155, 161 per the schematic.
    4. PDM outputting correctly but Allison not responding = PTO signal path to the Allison transmission is broken or the transmission-side interface has a fault. This crosses into chassis territory.
  4. If PTO engages mechanically but engine won't throttle, check the throttle card output (650-50015). Remote PTO Set Speed 1 is programmed at 875 RPM per the schematic.
    5. PTO on, boom interlocks met, but engine at idle = throttle card not commanding RPM. Per the schematic, the throttle card for this unit is 650-50015. Verify it is the correct card for the Cummins L9 / this configuration before replacing it.

Scenario 02 · Hydraulic
No Boom Function — PTO On, Outriggers Down, Pump Running
▼

Symptoms

  • PTO engaged, engine at correct RPM
  • Main pump is running (audible/felt)
  • All outriggers appear to be fully extended
  • Zero boom or elevator movement from any control

Step-by-Step Diagnosis

  1. Individually verify each outrigger switch is activating. "Down" visually is not the same as "switch made." Each leg has its own switch.
    2. One leg 90% extended might not have reached its switch actuation point. All switches must make. Probe or observe each switch individually.
  2. Confirm the outrigger interlock solenoid is energized. Check for correct voltage at the solenoid with all outriggers confirmed down.
    3. No voltage at interlock solenoid with all switches confirmed = interlock control module fault or wiring break between module and solenoid.
  3. Confirm the aerial device/outrigger selector valve is in aerial device mode (de-energized). Check the tailshelf selector switch position.
    4. Selector valve stuck in outrigger mode = oil is blocked from reaching the lower control valve. This is a hydraulic block, not an electrical fault — but caused by a solenoid issue.
  4. Check standby pressure at the pump compensator test port. Is the pump producing any pressure?
    5. Correct standby present with zero function = load-sense signal to spools is not being generated. Pilot system or upper controls interlock trigger issue. No standby = pump or load-sense circuit fault.
Root Cause Priority Order 1) One outrigger switch not making — most common. 2) Interlock solenoid not energized (wiring or module). 3) Selector valve in wrong mode. 4) Pilot system or blocking valve not opening for upper controls. 5) Pump not building standby pressure (pump or load-sense circuit fault).
Scenario 03 · Hydraulic
Cylinder Won't Hold Position — Slow Drift Under Load
▼

Symptoms

  • Boom or elevator slowly drifts down when lever is in neutral
  • Or: cylinder drifts on a loaded hold (winch, jib)
  • Other functions work normally
  • No visible external hydraulic leak
Safety Issue A holding valve that allows cylinder drift is a safety failure — do not return the unit to aerial service until corrected.

Step-by-Step Diagnosis

  1. Identify which cylinder is drifting by loading each independently and observing over a few minutes.
    2. Isolating to one cylinder narrows the cause to that cylinder's holding valves — not the pump or main circuit.
  2. Perform the holding valve test: Position the cylinder under load. Disengage PTO. Fully shift the manual lever for that function. Hold momentarily to allow oil flow to tank. If the cylinder does not move, the extend holding valve is OK. If it slowly retracts, the holding valve is leaking.
    3. This test distinguishes a leaking holding valve from an internal cylinder bypass. If the holding valve test passes but the cylinder still drifts with PTO off and lever neutral, the cylinder has internal bypass.
  3. If the holding valve tests as leaking, determine whether it's contamination (debris in the valve seat) or wear. A cartridge valve can often be cleaned; a severely worn seat requires replacement.
  4. If the holding valve tests as good but drift continues, the cylinder piston seal is bypassing internally. The cylinder requires service.
Root Cause Priority Order 1) Holding valve leaking (pilot operated check or counterbalance valve) — most common on high-hour units. 2) Debris lodged in holding valve seat — can be cleaned. 3) Internal cylinder piston seal bypass. Use the test procedure to distinguish valve from cylinder before disassembling either.
Scenario 04 · Hydraulic
Pump Cavitation and Noise After Hydraulic Repair
▼

Symptoms

  • Whining or unusual noise from pump immediately after hydraulic work
  • Spongey or inconsistent boom movement
  • Fluid temperature rising faster than normal
  • Fluid level checks out correct

Step-by-Step Diagnosis

  1. Back off immediately — do not run the pump hard. A pump cavitating on air will sustain internal damage if loaded heavily.
    2. Whining pump and spongey movement together after a repair = air in the suction side until proven otherwise. Treat it as that until you've checked every suction fitting.
  2. Inspect every suction-side fitting opened during the repair. A fitting not fully torqued will pull air under suction vacuum without leaking fluid under pressure.
    3. This is the most commonly overlooked cause of post-repair cavitation. Even one slightly loose fitting on the suction side can introduce persistent air.
  3. Bleed the system: cycle all functions slowly and repeatedly at minimal load to work trapped air back to the reservoir.
  4. If cavitation noise continues after 10–15 minutes of slow cycling, there is still an active air entry point. Remove, inspect, and reinstall — don't just retighten.
Don't Condemn the Pump Post-repair cavitation is almost always air in the suction circuit — not pump damage. Replace the pump without fixing the air entry and the new pump will cavitate too.
Root Cause Post-repair cavitation = air in suction circuit. Source: loose suction fitting (most common), low fluid after adding components back, or not pre-filling new components before installation. Resolution: torque all suction fittings, top off fluid, bleed slowly. Only evaluate the pump itself if cavitation persists after confirming an air-free suction circuit.
Scenario 05 · Electrical
DC Stowage Pump Inoperative — Boom Extended, Engine Down
▼

Symptoms

  • Engine stopped or PTO disengaged with boom elevated
  • DC stowage pump switch activated — no pump motor noise
  • OR: pump motor runs but boom doesn't retract
Treat This as Urgent If the boom is elevated and the stowage pump won't work, establish a safe lowering procedure per your company's protocols before beginning diagnosis.

Step-by-Step Diagnosis

  1. Check vehicle battery state of charge. The DC pump motor draws significant current — a discharged battery will produce weak or no pump output that looks like a failed motor.
    2. Low battery is the fastest thing to check and the most commonly overlooked. If the truck has been sitting with the engine off, battery may not have enough charge to run the DC pump effectively.
  2. Confirm the PDM pump relay is energized when the stowage pump switch is activated. Check the PDM connector center screw is fully tightened.
    3. The PDM relay is what sends power to the DC pump motor. If the relay isn't energized, no power reaches the motor regardless of battery state.
  3. Check DC pump motor wiring — power supply to pump and ground return.
    4. A high-resistance connection in the supply or ground path produces weak pump performance that looks exactly like a failing motor. Check voltage at the pump terminals under load.
  4. If motor runs but boom won't retract, the stowage control valve isn't opening. Check the valve solenoid wiring and command signal.
Root Cause Priority Order 1) Low battery voltage — most commonly overlooked. 2) PDM pump relay not energizing (check connector center screw). 3) High resistance in DC pump supply or ground wiring. 4) Valve solenoid command signal missing (motor runs, no movement). 5) DC pump motor failure. Work through in order — the motor itself rarely fails first.

✓ Correct. All functions equally slow = problem is upstream of all valve spools. The first thing to verify is oil level (with correct conditions — booms stowed, outriggers retracted, vehicle level). Low oil level and low pump output are far more common causes of uniform slowness than section compensator or interlock issues.

Treat the AI like a senior tech standing next to you. Tell it what you've already done. It should tell you what to do next — not repeat what you already tried.

At each step, tell me what I'm testing, what tool I need, what I'm looking for, and what each possible result tells me about where the fault is."

Getting the Most Out of This

Every prompt above is a starting point. After you get the first answer, keep going. The best diagnostic conversations are two-sided — push back, add more context, tell the AI what result you got, and ask what it means.

The other modules in this app are your reference. Come back here when you want to ask deeper questions. Use the two together: read the module, then use the AI to go further on the specific thing you don't understand yet.
